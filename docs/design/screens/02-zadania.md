# Zadania (widok kolekcji)

Makieta: ekran `zadania`; ustawienia `uklad` (lista / tablica), `opcje` (otwarte = okienko Opcji widoku).

- Zapisane widoki jako pigułki, przełącznik Lista / Tablica, przycisk Opcje widoku, rekord w prawym panelu.
- Status = kształt + kolor fazy (przerywane kółko → do zrobienia, wypełnienie wycinkiem → w realizacji, pełne z ptaszkiem → gotowe). Grupa „Gotowe” domyślnie zwinięta.
- Wiersz: status · ID mono · tytuł · kapsułki (priorytet, etykiety, termin z ikoną kalendarza — tylko gdy jest termin) · awatar. Spóźnione terminy na czerwono, pełna data w podpowiedzi.
- **Opcje widoku**: wiersze z ikonami (Grupowanie, Sortowanie, Pokaż puste grupy…), kolumny włączane kapsułkami z ptaszkiem.
- Tablica: kolumny wg statusu, karty bez ramek na `--bg-raised`.
